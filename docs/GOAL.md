- egui 의존성 제거
- 별도의 gui 라이브러리 없이 pure opengl 혹은 directx 기반으로 재 작성 (gpu 기반 렌더링)
- 간단한 draw를 위한 코드와 이를 이용한 앱을 구현하기 위한 최소한의 간단한 ui 프레임워크 작성
- immediate rendering 방식을 쓰지 않음으로 cpu 및 gpu 사용량 최소화
- 폰트 렌더링 부분만 따로 필요하면 라이브러리를 받으면 됨.
- 폰트는 Ubuntu-Light 사용. 폰트 파일을 알아서 다운받아서 적당한 위치에 놓고 이거를 코드에서 로드해서 사용. 바이너리 안에 포함되어야함
- 최종적인 gui는 현재 gui와 최대한 비슷하게 (docs/screenshot.png 에 현재 gui 스크린샷이 있음)
- 기능은 현재 기능과 동일하도록
- 중요한점: overlay 모드를 작동했을때 배경이 완전히 투명이 되어야 함
- 최종적으로 컴파일하면 단일 exe 실행파일이 되도록 하려고 함
- 실제로 컴파일을 해서 작동이 되는지 확인해야함
- 실제 프로그램 실행 후 나오는 gui 화면이 docs/screenshot.png 과 비교해서 최대한 동일한지 실제로 확인해야함
- 실제 프로그램 실행 후 overlay 버튼까지 직접 눌러봐서 배경이 투명해 지는지 확인해야 함
- 실제 프로그램 실행 후 문제가 없는지 확인해야 함
- 위에 실제 프로그램 실행 후 테스틑를 위해 스크린 캡처 덤프 기능과 간단한 ui 자동화 기능을 같이 구현해서 테스트 해야 함
